# Task-06: Hosting Static Website with GitHub Pages

## 📌 Objective
Deploy a simple static HTML website using GitHub Pages to showcase my DevOps Internship portfolio.

---

## 🛠 Tools Used
- Git
- GitHub
- GitHub Pages
- HTML
- CSS
- VS Code

---

## Project Overview

In this task, I created and deployed a static portfolio website using GitHub Pages.

The website highlights:
- Internship overview
- Tools & technologies used
- Completed DevOps tasks
- Structured project organization

The site is hosted directly from the `main` branch of the repository.

---

## Steps Performed

1. Created `index.html` and `style.css`
2. Added structured portfolio content
3. Pushed project to GitHub repository
4. Enabled GitHub Pages from:
   - Settings → Pages
   - Branch: `main`
   - Folder: `/ (root)`
5. Verified the live deployment link

---
